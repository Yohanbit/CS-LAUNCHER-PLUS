This launcher packages the unmodified, dynamically loaded libmobileglues.so
from the official MobileGlues 2.0.0 plugin APK for ARM32 and ARM64.
The plugin UI and its unrelated libraries are not included.
ANGLE is not included by this integration. Use the native GLES driver.
Minimum renderer requirement reported by upstream: OpenGL ES 3.0.

https://github.com/MobileGL-Dev/MobileGlues-release/releases/tag/V2.0.0

The launcher source and packaging workflow are available in this fork.
To test an interface-compatible modified library, replace the CI download step
with your built libmobileglues.so in src/main/jniLibs/<abi>/ and rebuild the APK.
No additional restrictions on modification or reverse engineering for debugging
changes to this LGPL-covered library are imposed by this integration.

Packaging verification is not an on-device compatibility or performance test.
