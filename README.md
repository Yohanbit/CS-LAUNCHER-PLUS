## Tu mundo, a tu manera

Una edición comunitaria de **CS Launcher Plus**, con inicio limpio, controles personalizables y ajustes de rendimiento agrupados. No es un proyecto creado desde cero: conserva la autoría y las licencias de sus bases.

| Jugar | Ajustar | Entender |
| :--- | :--- | :--- |
| MobileGlues 2.0.0 integrado | FPS Unlimited, Manual u Original | Diagnóstico opcional, sin promesas de FPS |
| Librerías Android LWJGL incluidas | Resolución dinámica opcional | Menús recuperan la resolución manual |
| Instancias y controles personales | Opciones de calidad reversibles | Historial y notas de cambios técnicos |

## Instalación

1. Abre **[Releases](https://github.com/Yohanbit/CS-LAUNCHER-PLUS/releases)** y descarga `Unamed.launcher.apk`.
2. Android 5.0 o superior; APK para ARM64 y ARM32. Los requisitos del juego y del entorno Java pueden ser mayores.
3. Si ya usas esta edición, intenta actualizar sin borrar tus datos. Haz una copia de tus mundos antes de cambiar de launcher.

Es una compilación de prueba. La resolución dinámica todavía escala el framebuffer completo: el HUD del mundo no tiene resolución independiente. El rendimiento depende del dispositivo, el mundo, los mods y la temperatura.
